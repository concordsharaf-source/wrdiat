# نظام الورديات (wrdiat)

تطبيق عام لأي مؤسسة أو فرع: قناة، مطعم، مستشفى…

## الدخول
- **الأدمن:** أول إيميل يُسجَّل يصبح الأدمن.
- **الموظف:** رقم دخول + رمز يصدرهما الأدمن.

## الأقسام
عدد غير محدود (صوت، تصوير، مطبخ، كاشير…).

## اليوم
يمكن تقسيم اليوم لأكثر من موظف بفترات: من – إلى.

بيانات Firebase تحت `orgs/wrdiat/` حتى لا تختلط مع تطبيقات أخرى.
